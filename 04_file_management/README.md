# Manage files

## How to create files?

```bash
touch new-file.txt -> to create an empty textfile
```
```bash
vim "filename.txt" to open editor in vim or
nano "filename.txt" for nano
```

## How to create a directory

```bash
mkdir -> make directory
mkdir "directory-name" at the preferred location
```

## How to delete a file

```bash
rm -> remove
rm "filename" to delete or
rm -i mydir/* to remove all files one by one
```

## How to move files

```bash
mv -> move
mv "filename" "tonewlocation"
ex.
mv readme.md dir2/subdir
```
